# 121 – Abwesenheitsnotizen nur für die Raidleitung

Entschieden am 2026-11-19. Ergänzt ADR 069 und 082: Für die Planung reicht anderen Spielern der Status. Persönliche Gründe dürfen nur die in FR-12.15 genannten Rollen lesen. Die API filtert den Freitext auch in den Antworten auf Schreibvorgänge; bestehende Notizen brauchen keine Migration.
