# 122 – Rechte für Raids und Serien begrenzen

Owner-Entscheidung, 2026-11-19, #246. Ergänzt ADR 010, 109, 112 und 121.

Die Kontorolle allein unterscheidet weder Serien noch die Aufgaben der einzelnen Raidassistenten. Deshalb werden Geltungsbereich und Aufgaben getrennt verwaltet (FR-1.11–13). Die Ausnahme für einen einzelnen Termin soll eine Vertretung ermöglichen, ohne ihr die ganze Serie zu übertragen. Die namentliche Leiterliste ist kein Ersatz für eine Rechteprüfung: Sie kann eine konfigurierte Zuständigkeit begrenzen, erteilt aber allein keine zusätzlichen Aktionsrechte.
